# Senior AI / ML Engineer

Remote (UTC-1 to UTC+2 (Europe)   Engineering   Full-time

## About the Role

Join our team to build and shape the revolution to supercharge AI assisted coding that transform how enterprise teams validate, implement and ship software. As part of our early machine learning team, you'll create NLP systems that understand software specifications, requirements and codebases to create recommendation engines that accelerate development workflows.

## Responsibilities

- Architect NLP and LLM-based systems for intelligent spec, code analysis and requirements matching
- Build recommendation engines that surface the right requirements based on spec context, project scope, team setup, and existing codebase conventions
- Develop semantic search across enterprise software specs, requirements, and code repositories
- Create developer productivity tools powered by machine learning insights from development workflows
- Extend our ML/LLM technical architecture, evaluation standards, and engineering practices as the product grows
- Contribute to product strategy by identifying AI opportunities in enterprise software development processes
- Actively participate in building a positive, inclusive, and learning-driven team environment
- Stay current with the latest research and ML/AI innovations

## Requirements

- 5+ years building production ML systems for technical / enterprise applications
- Experience deploying, evaluating, and monitoring ML models in production, including performance metrics, drift detection, and continuous improvement
- Hands-on experience building LLM-powered systems (for code generation, review, or documentation automation) including retrieval-augmented generation (RAG) over code and document corpora
- Strong LLM evaluation discipline: building eval harnesses, prompt engineering, and fine-tuning where appropriate, with a focus on correctness and regression control
- Experience with vector databases and embeddings for semantic code search and similarity matching
- Expert-level Python with deep knowledge of ML frameworks (e.g. TensorFlow, PyTorch) and NLP libraries (e.g. spaCy, transformers)
- Enterprise software experience including API design, microservices, and cloud deployment
- MLOps experience: model/inference serving, deployment pipelines, and managing latency and cost in production
- Excellent communication skills in English, both written and verbal
- Ownership mentality with end-to-end feature delivery responsibility
- Proactive approach to proposing and implementing technical improvements
- Ability to evaluate trade-offs and balance scalability, maintainability, and performance
- BONUS POINT: Experience with agent / tool-use frameworks (e.g. LangChain) for multi-step reasoning over repositories
- BONUS POINT: Experience with observability platforms (e.g. Grafana, Axiom) for monitoring system health, model performance, and production telemetry

## Compensation

skills, and location. We offer a higher salary in line with qualifications and
experience.
